# 防犯カメラ AI 異常検知システム Pro (Surveillance AI Monitor Pro)

本プロジェクトは、定点防犯カメラの録画映像から異常や不審な動きを自動解析・検出するデスクトップGUIアプリケーションです。

**YOLO (Ultralytics / OpenVINO)** による高速・高精度な物体検知（人物・車両・動物等）と、**LM Studio** で動作するローカル多角言語モデル（VLM: Vision-Language Model）を連携させることで、プライバシーを保護した完全ローカル環境での高度な時系列・文脈解析を実現します。

---

### 💡 主な特長 (Features)

- **YOLO × LM Studio (VLM) のハイブリッド解析**
  - 第1段階: YOLOが映像内の人物や車両などの対象オブジェクトを高速に検知。
  - 第2段階: 検知された前後のフレーム群を LM Studio（Gemma 4 等）へ送信し、「侵入・不審行為・滞留」などの文脈や異常の有無をAIが多角的に判定。
- **マルチハードウェア自動検出 & アクセラレーション**
  - PCの構成を自動スキャンし、Intel iGPU / Intel NPU (OpenVINO)、NVIDIA dGPU (CUDA)、CPU から最適な推論デバイスを選択可能。
- **動的フレームサンプリング（高精度キャプチャ）**
  - 通常時は指定間隔（例: 0.5秒）で軽量スキャンし、物体検知時には自動で追跡モード（高頻度サンプリング）へ切り替えて前後の詳細な動きをキャプチャ。
- **実時刻を反映した画像保存・ログ出力**
  - 動画ファイル構造・タイムスタンプから実際の撮影日時を復元し、撮影日時入りのファイル名保存および CSV ログを出力。
- **直感的な CustomTkinter GUI**
  - 検出対象クラスの一覧モーダル選択、依存ライブラリの自動チェック＆修復、AIによるパラメータ自動最適化、プログレスバーによる進捗視認性を完備。
