# 防犯カメラ AI 異常検知システム (Surveillance AI Monitor)

本プロジェクトは、定点防犯カメラの録画映像から異常や不審な動きを自動解析・検出するデスクトップ GUI アプリケーションです。

**YOLO (Ultralytics / OpenVINO)** による高速・高精度な物体検知（人物・車両・動物等）と、**LM Studio** で動作するローカル多角言語モデル（VLM: Vision-Language Model）を連携させることで、プライバシーを保護した完全ローカル環境での高度な時系列・文脈解析を実現します。

---

## 💡 主な特長 (Features)

- **YOLO × LM Studio (VLM) のハイブリッド解析**
  - **第1段階:** YOLO が映像内の人物や車両などの対象オブジェクトを高速に検知。
  - **第2段階:** 検知された前後のフレーム群を LM Studio（Gemma 4 等）へ送信し、「侵入・不審行為・滞留」などの文脈や異常の有無を AI が多角的に判定。
- **マルチハードウェア自動検出 & アクセラレーション**
  - PC の構成を自動スキャンし、Intel iGPU / Intel NPU (OpenVINO)、NVIDIA dGPU (CUDA)、CPU から最適な推論デバイスを選択可能。
- **動的フレームサンプリング（高精度キャプチャ）**
  - 通常時は指定間隔（例: 0.5秒）で軽量スキャンし、物体検知時には自動で追跡モード（高頻度サンプリング）へ切り替えて前後の詳細な動きをキャプチャ。
- **実時刻を反映した画像保存・ログ出力**
  - 動画ファイル構造・タイムスタンプから実際の撮影日時を復元し、撮影日時入りのファイル名保存および CSV ログを出力。
- **直感的な CustomTkinter GUI**
  - 検出対象クラスの一覧モーダル選択、依存ライブラリの自動チェック＆修復、AI によるパラメータ自動最適化、プログレスバーによる進捗視認性を完備。

## 🚀 使い方 (Quick Start)

### 1. 依存ライブラリのインストール
Python 3.10 以上がインストールされている環境で、以下を実行します。

```cmd
pip install -r requirements.txt
```

### 2. アプリケーションの起動

```cmd
python yolo_ai_monitor_gui.py
```

---

## 📦 Windows用 EXEファイル化（ビルド・コンパイル）手順

Python 環境が入っていない Windows PC でもプログラムを直接起動できるように、実行ファイル（`.exe`）に変換する手順です。

### 1. ビルドツールの準備

```cmd
pip install -r requirements.txt
pip install pyinstaller
```

### 2. EXEファイルへのコンパイル

以下のコマンドを実行します。

```cmd
pyinstaller --noconfirm --onedir --windowed --collect-all customtkinter yolo_ai_monitor_gui.py
```

### 3. 完成ファイルの確認

実行完了後、`dist/yolo_ai_monitor_gui` フォルダ内に **`yolo_ai_monitor_gui.exe`** が生成されます。

> **配布時の注意:** 他の PC へ配布する場合は、`.exe` 単体ではなく **`yolo_ai_monitor_gui` フォルダ全体** を zip 等で圧縮して共有してください。
